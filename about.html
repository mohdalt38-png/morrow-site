About Morrow

Built for the days ahead.

Morrow started with a simple idea: activewear should look as sharp standing still as it does moving. The Core collection is the first step — a minimal hoodie set designed for training, travel, and everything in between.

Every piece is built with premium soft-touch fabric, an oversized silhouette, and the signature Morrow mark, now available across five colorways from the classic Default black to the standout Anti Venom.
